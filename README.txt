ROSHAN ZAMEER — DIGITAL FIELD NOTES PORTFOLIO

Files: index.html (content), style.css (design + colours in :root), script.js (interactions).
Keep the three files in the same folder and open index.html, or deploy the folder to GitHub Pages / Netlify.

Customise:
- Colours: the :root variables at the top of style.css (light) and the dark-mode blocks near the bottom.
- Projects, internship, tools and links: edit index.html.
- Email copy button: change the address in script.js.
Fonts load from Google Fonts.
